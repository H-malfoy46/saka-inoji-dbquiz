# 坂道×イコノイジョイ クイズ＆DBビューア

楽曲DB・メンバーDB を **見る／クイズで遊ぶ** ためのローカルアプリ。
画面上部のタブで切り替える。

| タブ | 中身 |
|---|---|
| **クイズ** | DBから毎回ランダムに4択問題を自動生成(15種類の枠組み) |
| **楽曲DB** | 楽曲843件の一覧・検索・絞り込み |
| **メンバーDB** | メンバー288名の一覧・検索・絞り込み(サイリウムカラーは色見本つき) |
| **報告** | 「この問題おかしい」と報告した内容の一覧 |

問題文を1問ずつ手で作るのではなく、「問題の枠組み(テンプレート)」を15種類用意して、
中身をDBから毎回引いてくる作りになっている。

## 遊び方

### かんたん(Macだけで遊ぶ)
`クイズを開く.command` を**ダブルクリック**。ブラウザが開いてすぐ遊べる。
終わるときは、開いたターミナルのウィンドウで `Ctrl+C`。

`index.html` をダブルクリックで直接開いても遊べる(サーバーなし)。

### スマホで遊ぶ（方法A: 同じWi-Fi・準備ゼロ）
1. Macで `クイズを開く.command` をダブルクリック
2. ターミナルに出る「スマホから → http://192.168.x.x:8765」のURLを、スマホのブラウザに入力

Macで起動している間だけ遊べる。外出先では遊べない。

### スマホで遊ぶ（方法B: ネットに置いて、いつでも遊ぶ）
このアプリは**ファイルを置くだけで動く**(サーバー側の処理が不要)ので、
無料の静的ホスティングにフォルダごと置けば、どこからでも遊べる。

置いたあと、スマホのSafariでそのURLを開き、
**共有ボタン → 「ホーム画面に追加」** すると、アプリのアイコンとして並び、
**電波がなくても遊べる**ようになる（ホーム画面用の設定と、オフライン用の仕組みを入れてある）。

置く候補:
| サービス | 特徴 |
|---|---|
| Netlify Drop | フォルダをドラッグ&ドロップするだけ。アカウント登録も後回しでOK |
| GitHub Pages | GitHubにリポジトリを作って置く。更新もgit pushだけ |
| Cloudflare Pages | 同上。表示が速い |

※ ネットに置くと、URLを知っている人は誰でも見られる状態になる点だけ注意。
※ ネットに置いた場合、報告は `reports.jsonl` には保存されず、スマホのブラウザ内に保存される
（「報告をまとめてコピー」でいつでも取り出せる）。

## 出題される問題の種類(15種類)

### 楽曲
| 枠組み | 例 |
|---|---|
| センター | 櫻坂46「Nobody's fault」でセンターを務めたのは? |
| クレジット | 「流れ弾」の作曲を担当したのは?(作詞/作曲/編曲/振付/MV監督) |
| 逆引き | ○○が編曲を担当したのは次のうちどれ? |
| 除外(否定形) | 次のうち、○○が作詞を担当して**いない**のは? |
| 収録CD番号 | 「桜月」が収録されているのは?(◯thシングル) |
| 収録CD名 | 「〜」が収録されているCDのタイトルは? |
| 発売年 | 「〜」がリリースされたのは何年? |
| 表題曲 | 次のうち、日向坂46の表題曲はどれ? |
| リリース順 | 次の4曲のうち最も古いのは? |
| センター逆引き | ○○がセンターを務めたのは? |

### メンバー
| 枠組み | 例 |
|---|---|
| 期 | 乃木坂46の○○は何期生? |
| サイリウムカラー | ○○のサイリウムカラーは? |
| 誕生日 | ○○の誕生日は何月? |
| 所属グループ | ○○が所属している(していた)グループは? |
| 同期 | ○○と同じ期のメンバーは? |

## 正確さのための仕組み

答えが一意に定まらない問題を出さないよう、次の処理を入れている。

- **【要確認】や「-」「不明」が入っている項目は、問題にも選択肢にも使わない**
- **複数人が併記されている項目(「秋元康、○○」など)は出題しない**(答えが一意にならないため)
- **誤答が実は正解、を機械的に排除**。例えば「○○が編曲していないのは?」では、
  誤答側の3曲すべてに本当にその人が関わっていることを確認している
- **表記ゆれの吸収**。「Acchan」と「Acchan(田中文人)」のような同一人物が
  正解と誤答に同時に出ないようにしている

※ 2000問を自動生成して上記の条件を検査し、違反0件を確認済み。

## DBビューア（楽曲DB / メンバーDB タブ）

Excelと同じ内容を、そのまま見やすい形で表示する。項目・構造はExcelから変えていない。

- **検索**: 曲名・CD名・作曲者・センター・グループ名などを部分一致でまとめて検索
  （スペース区切りで絞り込み。例:「日向坂 表題」「櫻坂 3期」）
- **絞り込み**: グループ、種類(表題/カップリング/ユニット/ソロ)、在籍(現役/卒業)
- **並び順**: Excelと同じ並び順がデフォルト。曲名順・五十音順・誕生日順にも変更可
- **行をタップ**すると、その曲/メンバーの全項目(作詞・作曲・編曲・振付・MV監督・備考・情報源など)が開く
- **サイリウムカラーは色見本つき**で表示（「ピンク×レッド」なら2色の丸が並ぶ）
- **【要確認】の項目は赤字**で表示されるので、未確定のデータがひと目で分かる

## 問題の報告

クイズで答えや選択肢がおかしいと思ったら、その問題の解説の下にある
**「この問題がおかしい？ 報告する」** から報告できる。

- 報告の種類(正解が間違っている／選択肢がおかしい など)を選び、補足を書いて送信
- **問題文・選択肢・アプリの正解・元データは自動で記録**されるので、何も書かなくても報告になる
- 報告は「報告」タブにたまる。**「報告をまとめてコピー」** で全文をコピーできるので、
  そのまま修正依頼に貼れる
- `serve.py` 経由で開いている場合は `reports.jsonl` にも1行ずつ保存される
  （`index.html` を直接開いた場合はブラウザ内のみに保存）

## DBを更新したとき

楽曲DB・メンバーDBのExcelを更新したら、次を実行するとクイズの中身も最新になる。

```
python3 build_quiz_data.py
```

これは2つのExcelを直接読んで `quiz_data.js` を作り直すスクリプト。
**Excelが正**なので、クイズとExcelの内容がズレることはない。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体(画面・出題ロジック・DBビューア全部入り) |
| `quiz_data.js` | Excelから生成したデータ |
| `build_quiz_data.py` | Excel → quiz_data.js を作り直すスクリプト |
| `serve.py` | ローカルサーバー(報告の受け取りも担当) |
| `クイズを開く.command` | ダブルクリック用の起動ファイル |
| `reports.jsonl` | 報告の保存先(報告が入ると自動で作られる) |
| `manifest.webmanifest` | ホーム画面に追加したときのアプリ名・アイコンの設定 |
| `sw.js` | オフラインでも動くようにする仕組み |
| `icons/` | ホーム画面用のアイコン画像 |
| `make_icons.py` | アイコンを作り直すスクリプト |

※ ネットに置く場合は、このフォルダの中身を**まるごと**アップロードする
（`serve.py` や `.command` は使われないが、あっても害はない）。
